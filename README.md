# 계약 한도 관리

## Windows에서 실행

Windows x64용 `ContractManager-v6.exe`를 실행합니다. 기존 대장을 이어서 사용하려면 `계약대장.xlsx`가 있는 폴더에 새 실행 파일을 넣고 엑셀에서 대장을 닫은 후 실행하세요. 대장이 없는 폴더에서 처음 실행하면 빈 `계약대장.xlsx`를 생성합니다. Python이 설치되어 있지 않아도 실행할 수 있습니다. 프로그램 제목에 `v6.0`이 표시됩니다. [v6.0 배포 페이지](https://github.com/aidenyoun/contract-manager/releases/tag/v6.0)

- **전체 계약**을 누르면 선택한 회계연도의 전체 계약 대장이 열립니다. **계약 업체**와 **한도 도달·초과 업체**를 누르면 해당 회계연도의 업체 목록과 누적 실적을 팝업으로 확인할 수 있습니다.
- **계약 등록**의 **기존 업체**에서 업체명이나 사업자번호로 전체 계약 이력을 검색할 수 있습니다. 업체를 선택하면 해당 사업자번호와 최근 계약의 업체명이 함께 입력됩니다. 처음 거래하는 업체는 두 항목을 직접 입력합니다.
- **총금액**에 부가세를 포함한 금액을 입력합니다. 부가세는 총금액의 10%로 자동 계산하며 원 미만은 버립니다. 공급가액은 총금액에서 부가세를 뺀 값입니다. 부가세를 직접 바꾸면 공급가액도 다시 계산됩니다. **면세**를 선택하면 부가세는 0원이고 총금액 전액이 공급가액입니다.
- **계약 대장**에서 회계연도와 검색어로 계약을 조회합니다. 행을 선택해 수정하거나 삭제할 수 있습니다. 누적 열은 검색 결과와 관계없이 해당 업체의 회계연도 전체 계약을 기준으로 합니다.
- **업체별 현황**에서 전체 계약 건수, 한도에 반영되는 횟수, 누적 공급가액, 잔여 한도를 확인합니다. 업체를 선택하고 **업체 계약 내역**을 누르면 해당 업체로 검색됩니다.
- **계약 대장**과 **업체별 현황**에서 열 제목을 클릭해 정렬합니다. 같은 제목을 다시 클릭하면 방향이 바뀝니다. 현재 정렬은 제목 옆 화살표로 확인할 수 있습니다.
- 회계연도 선택 목록과 엑셀에는 2025년~2030년이 기본으로 포함됩니다. 그 밖의 연도도 등록된 계약이 있으면 표시됩니다. 엑셀의 계약 대장과 연도 탭에는 공급가액, 부가세, 면세 여부와 업체별 누적 집계가 표시됩니다. 프로그램에서 계약을 등록·수정·삭제하면 갱신됩니다.
- 이전 버전 대장을 처음 열면 원본을 백업하고 기존 계약 금액을 그대로 공급가액으로 옮깁니다. 예전 계약의 부가세는 빈칸, 면세 여부는 `미확인`으로 표시합니다. 같은 이름의 시트를 직접 만들어 둔 경우, 프로그램이 추가하는 탭에는 `2025년 계약`처럼 별도 이름을 사용합니다.
- 계약을 저장할 때 직전 대장이 `계약대장.backup.xlsx`로 보관됩니다. 대장을 다른 PC로 옮길 때는 `계약대장.xlsx`도 함께 복사하세요. 여러 창에서 같은 대장을 편집할 수 없으며, 엑셀에서 열어 본 뒤 프로그램으로 저장할 때는 엑셀을 닫아 주세요. 계약 편집은 프로그램 화면에서 합니다.

## 계약 한도

같은 사업자번호로 등록된 계약을 계약일 기준 1월 1일부터 12월 31일까지 합산합니다. 업체별 현황의 업체명은 마지막 계약일의 표기를 따릅니다.

| 한 건의 공급가액 | 누적 공급가액 | 누적 횟수 |
| --- | --- | --- |
| 200만 원 이하 | 등록 불가 | — |
| 200만 원 초과 ~ 500만 원 이하 | 전액 반영 | 0회 |
| 500만 원 초과 | 전액 반영 | 1회 |

공급가액 합계 2억 원 또는 횟수 5회에 도달하면 한도 도달로 표시합니다. 어느 한도를 넘기는 등록·수정도 차단됩니다. 5회에 도달한 상태에서도 공급가액이 500만 원 이하인 계약은 누적 공급가액이 2억 원을 넘지 않는 범위에서 등록할 수 있습니다.

## 소스 실행 및 빌드

Windows x64에서 Python 3.12와 Tcl/Tk를 설치하고 `build-windows.cmd`를 실행하면 `dist/ContractManager-v6.exe`가 생성됩니다. 소스에서 실행할 때는 `python -m pip install -r requirements.txt`로 의존성을 설치한 뒤 `python app.py`를 실행하세요. 테스트는 `python -m unittest discover -s tests -v`로 실행합니다.
